# Código de conducta

Chatty es de quien lo usa y de quien lo mejora. Para que siga siendo un buen lugar:

## Lo que esperamos

- Trato respetuoso, aunque no estemos de acuerdo.
- Críticas al código, nunca a las personas.
- Paciencia con quien empieza: todos preguntamos lo obvio alguna vez.
- Español claro y directo, sin groserías.

## Lo que no se acepta

- Insultos, burlas, acoso o ataques personales.
- Lenguaje o imágenes sexuales, violentas o discriminatorias.
- Publicar datos privados de alguien (incluidos los de los seguidores de una instalación).
- Spam o promoción que nadie pidió.

## Si algo pasa

Repórtalo con **Report content** de GitHub en el comentario o issue, o con un reporte privado en
la pestaña **Security**. Quien mantiene el proyecto puede editar o borrar comentarios, cerrar
conversaciones y bloquear a quien no respete estas reglas.

Basado en el [Contributor Covenant](https://www.contributor-covenant.org), versión 2.1.
